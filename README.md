## 🌟 Overview

**CineVerse** is a full-stack, content-based movie recommendation system inspired by premium cinematic streaming platforms (Apple TV+, HBO Max). It leverages **Natural Language Processing (NLP)**, **TF-IDF (Term Frequency-Inverse Document Frequency) vectorization**, and **High-Dimensional Cosine Similarity** to recommend contextually relevant films based on plot summaries, thematic keywords, genres, directorial patterns, and lead cast.

### 1. Mathematical Formulation

#### **TF-IDF Term Weighting:**
$$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \log\left(\frac{1 + |D|}{1 + |\{d \in D : t \in d\}|}\right) + 1$$
Where:
- $\text{TF}(t, d)$ represents the sublinear frequency of token or bigram $t$ within document $d$.
- $\text{IDF}(t, D)$ scales down omnipresent terms and rewards domain-specific concepts.

#### **Pairwise Cosine Similarity:**
$$\text{Cosine Similarity}(u, v) = \frac{u \cdot v}{\|u\|_2 \|v\|_2} = \frac{\sum_{i=1}^n u_i v_i}{\sqrt{\sum_{i=1}^n u_i^2} \sqrt{\sum_{i=1}^n v_i^2}}$$

Cosine similarity computes the cosine of the angle between two multi-dimensional TF-IDF vectors in $\mathbb{R}^n$, providing length-invariant semantic proximity between movies.

## 📡 REST API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/movies` | Fetch all movies with optional `genre` and `sort_by` query parameters |
| `GET` | `/api/movies/{id}` | Retrieve comprehensive metadata for a specific film |
| `GET` | `/api/movies/featured` | Retrieve the flagship hero movie |
| `GET` | `/api/recommend/{id}?top_n=8` | Calculate top-N similar movies using TF-IDF & Cosine Similarity |
| `GET` | `/api/recommend-by-text?q=...` | Natural language plot/keyword similarity search |
| `GET` | `/api/search?q=...` | Instant title/genre autocomplete search |
| `GET` | `/api/genres` | Catalog breakdown by genre |
| `GET` | `/api/stats` | Academic summary of corpus size, vocabulary, and n-grams |
